# Career Blueprint AI – MVP 0.1

Erster klickbarer Prototyp für einen Bewerbungsassistenten.

## Enthalten
- Lebenslauf-Upload als vorbereitete Oberfläche
- Masterprofil
- Stellenanzeige einfügen
- Fachlicher Match-Score
- Wunsch-/Arbeitsmodell-Score
- einfacher ATS-/Keyword-Score
- Empfehlung
- lokale Speicherung und Archiv
- erster Bewerbungsentwurf

## Dateien
- `index.html`
- `style.css`
- `app.js`
- `data/sample-profile.json`

## GitHub + Netlify
1. Neues GitHub-Repository anlegen, z. B. `career-blueprint-ai`
2. Alle Dateien und den Ordner `data` hochladen
3. In Netlify: **Add new site → Import an existing project**
4. GitHub auswählen und Repository verbinden
5. Build command leer lassen
6. Publish directory: `/` beziehungsweise Root
7. Deploy starten

## Hinweis
Diese Version verwendet noch keine KI-API und liest PDF/Word-Dateien noch nicht automatisch aus.
